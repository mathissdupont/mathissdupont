## About Me

I am a Computer Engineering student working across **compiler and toolchain development**, **embedded and cryptographic security**, **AI infrastructure**, and **full-stack product engineering**.

My current work ranges from a statically typed language for policy-constrained AI agents to cross-platform secure firmware updates, cryptographic code analysis, digital identity, and production-oriented web platforms. My long-term research direction is **quantum computing and post-quantum systems**.

## Featured Engineering

| Project | Engineering focus | Main technologies |
| --- | --- | --- |
| **[Ingot](https://github.com/mathissdupont/ingot)** | A statically typed language and compiler for AI agents. Checks types, effects, policies, capabilities, and budgets before execution; emits portable Agent IR and includes a runtime, Python backend, MCP tooling, LSP, OCI packaging, and policy-derived sandboxing. | Rust, compiler design, type/effect systems, IR, LSP, MCP, OCI, containers |
| **[Secure Update Abstraction](https://github.com/mathissdupont/secure-update-abstraction)** | A hardware-independent secure firmware update orchestrator with signed manifests, anti-rollback, A/B trial boot, and platform adapters for EFR32, i.MX 8M Plus, and STM32MP1. | C11, CMake, OpenSSL, ECDSA, secure boot, embedded Linux |
| **[HeptaCert](https://github.com/mathissdupont/heptapus-certs)** | A full-stack event and certificate platform covering events, attendees, community features, transactional email, billing, moderation, and administrative operations. | FastAPI, Next.js, TypeScript, PostgreSQL, Redis, Docker |
| **[CryptoGraph](https://github.com/mathissdupont/CryptoGraph)** | A graph-based cryptographic API analyzer that detects crypto usage, models code context, applies risk rules, and produces CBOM-like output across multiple languages. | Python, static analysis, CPG/AST, NetworkX, Pydantic, Streamlit, Docker |
| **[WorldPass](https://github.com/mathissdupont/worldpass-real)** | A multi-surface digital identity platform built around decentralized identifiers and verifiable credentials, with optional blockchain and distributed-storage integrations. | FastAPI, React, Vite, cryptography, DIDs, VCs, Web3, Docker |
